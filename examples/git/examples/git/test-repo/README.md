# Configr Git Integration Demo

This repository demonstrates the integration between Configr's File Module and Git Module.

## Features Demonstrated

- **File Creation**: Using the File Module to create files
- **Git Operations**: Clone, pull, and commit operations
- **Version Control**: Proper git workflow integration
- **Rollback Support**: Complete rollback of all changes

## Files Created

- `configr-demo.txt`: Main demonstration file
- `.gitignore`: Git ignore file for the repository
- `README.md`: This documentation file

## Usage

This example shows how to:

1. Clone a repository
2. Create new files using the File Module
3. Commit changes to git
4. Rollback all changes if needed

## Integration Benefits

- **Automated Workflows**: File creation and git operations in one configuration
- **Consistent State**: All operations are tracked and can be rolled back
- **Dotfile Management**: Perfect for managing configuration files with version control
